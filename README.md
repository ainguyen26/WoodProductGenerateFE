# Frontend WoodProductGenerate

Frontend Vite + React + TypeScript cho man hinh sinh ma hang theo cong thuc:

`R + AA + BBB + CC + D + EEEE + FF + GG + HH`

## Chay local

```bash
npm install
npm run dev
```

Copy `.env.example` thanh `.env` neu can doi URL backend:

```env
VITE_API_BASE_URL=http://localhost:4000
```

Ung dung mac dinh chay tai `http://localhost:5173`.
